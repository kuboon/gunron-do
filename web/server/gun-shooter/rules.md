# 早見表

急ぐ人はここだけで遊べます。
理由はこの下の各節にあります。

## 遊び方

- 敵は立体です。金色に光る `e` の面が、まっすぐこちらを向いて正立していれば「`e` に戻った」状態です。
- 弾は3種類。`↺` と `↻` はこちら向きの軸で敵をひとコマ回し、`⇅` は手前の面の下の辺を軸に半回転（裏返し）させます。
- `e` に戻った敵に **e砲** を当てると撃破。
- `e` 以外に e砲 を当てると **反発** して、敵がさらにひとコマ回ってしまいます。コンボも切れます。
- 敵がすぐそばまで来ると、ライフが減ります。ライフが尽きたら終わりです。
- 3ウェーブ目からは、敵が赤い弾を撃ってきます。どの弾でも撃ち落とせます（25点）。当たるとライフが減ります。

## 読み方

どの弾を撃てばいいかは、敵に出る印で読めます。

- **金の針**：`e` の面がどちらを向いているか。立体の真ん中から `e` の面を通って外へ伸びています。体の裏に回っても透けて見えます。
- **緑の輪**：`⇅` を撃ったときに手前へ来る場所。
- **緑の点線**：`↺` `↻` を撃ったときに、針先が通る道。

なので、戻し方はいつも同じです。

1. `↺` `↻` で、金の針の先を緑の点線にそって回し、緑の輪に入れる
2. `⇅` で `e` の面を手前に持ってくる（正十二面体は、1 と 2 をもう一度やることもあります）
3. `e` の面が正面に来たら、`↺` `↻` で `e` を正立させる
4. e砲

狙っている敵の下には「あと何手か」が常に出て、弾を当てるたびに近づいたか（▼）遠ざかったか（▲）も表示されます。
画面右下では、いま撃つとよい弾のボタンが光ります。

## 点数

- 撃破1体で、その敵の群の位数 × 10 点。コンボ中はさらにコンボ数倍（最大10倍）です。
- 最短の手数で `e` に戻してから倒すと **PERFECT**。点数が2倍になります。
- e砲 は貫通します。一直線に並んだ `e` の敵をまとめて撃ち抜くと、2体目は2倍、3体目は4倍になります。

# 敵と群

敵の立体を自分自身に重ねる回転は、全体で群をなします。
敵の「いまの向き」は、その群の元です。

| 敵     | 形           | 群 | 位数 | ひとコマ |
| ------ | ------------ | -- | ---- | -------- |
| 三角   | 正三角形の板 | D₃ | 6    | 120°     |
| 四角   | 正方形の板   | D₄ | 8    | 90°      |
| 四面体 | 正四面体     | A₄ | 12   | 120°     |
| 立方体 | 立方体       | S₄ | 24   | 90°      |
| ボス   | 正十二面体   | A₅ | 60   | 72°      |

ボスの A₅ は、5次の交代群です。
正二十面体群とも呼ばれ、単純群の中で一番小さい非可換群です。

# なぜ `e` の面を見ればいいのか

これらの立体の回転は、「どの面が手前に来ているか」と「その面がどちら向きに立っているか」の組で、ちょうど一つに決まります。
たとえば立方体なら、手前に来る面が6通り、その面の向きが4通りで、6 × 4 = 24。
これは S₄ の位数に一致します。
正十二面体なら 12 × 5 = 60 で、A₅ の位数です。

なので「`e` の面が手前で正立している」と「敵の向きが単位元 `e`」は、まったく同じことを言っています。
金色の `e` が読めたら、その敵は `e` です。

板（D₃、D₄）だけは裏表があるので、「表か裏か」と「向き」の組で数えます。
正方形なら 2 × 4 = 8 です。

# 弾は生成元

`↻`（または `↺`）と `⇅` の2種類だけで、どの群も全部の元が作れます。
つまりこの2つは、それぞれの群の**生成元**です。

- `↻` は位数 n の回転です（`n` はひとコマで1周する回数。四角なら4）。`↻` を n 回撃つと元に戻ります。
- `⇅` は位数2の回転です。2回撃つと元に戻ります。
- `↺` は `↻` の逆元です。`↺` を撃つのは `↻` を n − 1 回撃つのと同じです。

弾は、いつも**こちらから見て**決まった軸で敵を回します。
いまの向きが `g` の敵に弾 `s` を当てると、向きは `s·g` になります（左からかける）。
同じ弾は、敵がどんな向きでも、画面の上では同じ回り方をします。

## 最短の手数

`e` からの距離（何発で戻せるか）の最大値は、群ごとに決まっています。

| 群 | 位数 | 最遠 |
| -- | ---- | ---- |
| D₃ | 6    | 2手  |
| D₄ | 8    | 3手  |
| A₄ | 12   | 3手  |
| S₄ | 24   | 6手  |
| A₅ | 60   | 9手  |

これは、生成元 `↺` `↻` `⇅` で描いた**ケイリーグラフ**の直径です。
PERFECT は、ケイリーグラフ上の最短経路をたどったということです。

上の「読み方」の手順は、いつでも `e` に戻せる手順ですが、いつも最短とは限りません。
D₃、D₄、A₄、S₄ では平均でちょうど最短と同じ手数になり、A₅ だけは平均で少し（4.63 手に対して 4.87 手）遠回りになります。

最初の2ウェーブでは、次の一手そのもの（`↻` など）も出ます。

# 反発のしくみ

e砲 は「単位元にしか効かない」弾です。
`e` 以外に当たると、ランダムな生成元をひとつ敵にかけて跳ね返ります。
戻すのにかかる手数は、ひとつ増えるか、ひとつ減るかのどちらかです。
運が良ければ近づきますが、コンボは必ず切れます。
