---
title: テトラ道のルール
summary: 正四面体を120°ずつ回す操作の盤面をなぞり、回転が打ち消し合って元の向きに戻る経路を探します。
---

## マスが表すもの

盤面は5×5で、どのマスにも正四面体を回す操作が一つ入っています。

正四面体には角が4つあり、`e` と書かれた面を囲む3つに `a`、`b`、`c` の印が付いています。
`e` の面は、元の向きのときに手前を向いている面です。
つまり印の付いた3つは、正面から見えている三角形の3つの角で、残る1つ——`e` の裏に隠れている角——には印がありません。
マスの操作は、印の付いた三つの角のどれかを軸にして、正四面体を120°回すことです。

マスに描かれた小さな三角形は、この `e` の面を正面から見た形です。
点が置かれている位置が、そのまま立体の角に対応しています。
塗りつぶした点は時計回り、白抜きの点は反時計回りを表します。
反時計回りのマスには `a⁻¹` のように逆元の記号が入ります。

軸は空間に固定されていて、四面体といっしょには動きません。
だから何回回しても、四面体が最初と同じ位置に収まる向きは12通りしかなく、そのうちの一つが元の向きです。

## なぞる

上下左右に隣り合うマスを、指またはマウスでつないでなぞります。
斜めにはつながりません。
一度通ったマスをもう一度通ることもできません。

なぞった順に回転が重なります。
最初のマスが元の向きの四面体を回し、次のマスがその結果をさらに回します。

一つ前のマスに指を戻すと、その手は取り消されます。
四面体も取り消した分だけ戻るので、長い経路は先を読まずに手探りで組み立ててかまいません。

## 消える条件

指を離した時点で四面体が元の向きに戻っていれば、なぞったマスが消えます。
戻っていなければ、なぞりが取り消されるだけです。
時間は減らないので、長い経路は当たりを付けて引いてみてください。
ただし、**6手以内に一度は戻す**必要があります（後述）。

2マスだけなぞったときは別の扱いになります（[2マスで入れ替える](#2マスで入れ替える)）。

ただし、**打ち消し**を除いたあとに3つ以上残る経路でなければ**成立**しません。
打ち消しとは、隣り合う `a` と `a⁻¹` のように、同じ軸で向きが逆の2手のことです。
この2手はどこにあっても回転としては何もしないので、除いたうえで長さを数えます。

なぞっている間、打ち消し合っている部分は**中抜きの橋**として描かれます。
線は道の両端だけの2本のレールになり、そのマスも塗りが抜けて枠だけになります。
渡れるけれど、中身は数に入らない——という意味です。
指を離す前に、その経路のどこが数に入らないかが見えます。

消えたマスの上にあったマスは下に落ち、空いた分は上から補充されます。

## 6手以内に一度は戻す

長い経路には、もうひとつ条件があります。
**一度も元の向きに戻らないまま6手進むと、その経路はもう成立しません。**
6手目に入った時点で線全体が**破線**に変わり、あとは何をなぞっても消えません。
橋の中抜きとは別の表示です——こちらは繋がっていない、という意味なので。

戻りきる経路は6手までです。
6手使っても戻っていなければ、次に戻れるのは7手目以降——つまり間に合いません。
だから破線になるのは「超えた瞬間」ではなく「使い切った瞬間」です。

### 数えるのはマスではなく手

**打ち消しはこの6手に入りません。**
スコアで数えないものを制限でだけ数えるのは筋が通らないので、どちらも打ち消しを除いたあとの手数で数えます。
`a` と `a⁻¹` は向きを回して回し戻すだけなので、制限に捕まえるものがありません。

払うものが無いわけではありません。
打ち消しの2マスはマスであり、なぞる時間もかかります。
払わないのは6手の枠だけです。

途中で戻れば、そこからまた6手数え直しです。
なので長い経路は「長い一本の当てずっぽう」ではなく、**短い成立をいくつも、指を離さずに繋いだもの**になります。
5手で戻し、続けて4手で戻し、さらに6手で戻せば、15手の経路が一度に成立します。

この条件が無いと、長さは考えなくても手に入ってしまいます。
四面体の向きは12通りしかないので、指を動かし続けて `e` が戻った瞬間に離せばよく、盤面を読む必要がありません。
実際に測ると、盤面を一切読まずに歩くだけで平均7マス、3回に1回は12マス以上が取れていました。
読む人との差は1.5倍しかありません。

6手の制限を入れると、読まずに歩く人の12マス以上は13%、18マス以上は3%まで落ちます。
一方で読む人は今より伸びます。
一本の長い経路を当てるより、短い成立を繋ぐほうが確実だからです。

打ち消しを6手に数えないぶん、彷徨う人は少しだけ得をします。
同じ条件で測り直すと、何か消せる確率が22%から36%へ、1回あたりの平均が1.2マスから2.1マスへ上がります。
ただし**この制限が止めたかった長い経路は戻ってきません**。
12マス以上が取れる確率は、打ち消しを数えても数えなくても変わりませんでした。
打ち消しは1手行き過ぎた人を引き返させるだけで、どこかへ連れていってはくれないからです。
読む人の成績も変わりません。

なぜ6かというと、この数を上げても、**その人が実際に先を読める範囲を超えた分は何の役にも立たない**からです。
5手先まで読む人の成績は、制限が5でも6でも7でも8でも同じです。
彷徨う人だけが上げた分だけ得をします。
なので制限は「読める範囲」に置くのが正しく、その範囲をこのゲームが実際に人へ示しているのはチュートリアルの最後——`a b c a b c` の6手です。
6手なのは「3手を覚えて、もう一度」だからで、これがこのゲームで6手を読むときの読み方であり、最初のレッスンが人に求められる限度でもあります。

数え直しの起点になるのは、**元の向きに戻っていて、かつそこまでに打ち消しを除いて3手以上残っている**地点です。
ただし打ち消しは6手に数えないので、起点にならない打ち消しの組をいくつ並べても経路は死にません。
**橋は最初から使えます。**
これが次の「橋」です。

## 打ち消しだけの経路も消える

隣り合う `a` と `a⁻¹` の2マスだけをなぞると、そこも消えます。
`a` `a⁻¹` `b` `b⁻¹` のように打ち消しの組をいくつ連ねても同じで、全部が打ち消し合う経路なら消えます。

回転としては何もしていないので、成立には数えません。
消去にも成立にもコンボにも入りません。
使いどころのない逆手の組を盤面から外すための手です。

## 2マスで入れ替える

打ち消しにならない2マスをなぞると、その**2マスが入れ替わります**。

`a` と `b` のように打ち消し合わない組み合わせが対象です。
`a` と `a⁻¹` なら打ち消しとして消えるほうが先に働きます。
同じ手が2つ並んでいるところを入れ替えても、見た目は何も変わりません。

これは何にも数えません。
消去にも、成立にも、コンボにも入りません。
かかるのは時間だけです。

盤面から何も減らず、上から知らないマスが落ちてくることもありません。
だから入れ替えが訊いてくるのは**どの2つか**だけで、それは叩いて決めることではなく読んで決めることです。
使えない向きのマスを捨てるのではなく、使える場所へ動かす手だと思ってください。

## 数えるもの

3つ数えます。

- **消去** — 消えたマスの数の合計。ただし打ち消し合うマスは除きます。
- **成立** — 元の向きに戻った回数。**1回のなぞりの中で何度戻ったかを、それぞれ数えます。**
- **コンボ** — 1回のなぞりが何回の成立でできていたか、その最大値。

どの数も、数えるのは打ち消しを除いたあとの長さです。
7マスなぞって打ち消しが1組あれば、消去に入るのは5です。
打ち消しを通って離れた場所の成立パターンを拾うこともできますが、打ち消し分はスコアに入りません。

### 成立は「なぞった回数」ではありません

6手以内に一度は戻す決まりがあるので、長いなぞりは必ず成立の連なりです。
12マスを一度になぞって途中で3回戻っていたなら、それは**1回のジェスチャーでした4回の成立**です。
成立は4つ増え、コンボは4になります。

数えるのはジェスチャーではなく、その中身です。

### コンボの上限は8

ひとつの成立には打ち消しを除いて最低3手が要り、盤面は25マスしかありません。
3 × 8 = 24 なので、8回が限界です。
9回目には27マス必要になります。

打ち消しで水増しはできません。
`a` `a⁻¹` を挟むと向きは元に戻りますが、その区間は打ち消しを除くと0手なので成立には数えません。
橋として通り道にはなりますが、コンボは増えません。

1回の持ち時間は60秒です。
「始める」を押してから3、2、1と数えたあとに始まります。
成立しなかった経路に罰はありません。

## 立体の見かた

画面の四面体は、いまの向きをそのまま映しています。
面の一つに `e` が書いてあり、これが手前に正しく見えている状態が元の向きです[^e]。
経路が閉じた瞬間に `e` が光るので、指を離す前に成立を確かめられます。

四面体は、マスをつなぐたびにその場で回ります。
1手あたり0.3秒かけて回るので、全部の回転を目で追うと、そのぶん時計が減ります。
見て確かめるか、字を読んで先に決めるか——そこが持ち時間の使いどころです。

[^e]: `e` は群の単位元の記号で、「何もしない操作」を指します。

## 音と、残り10秒

消えたときは経路の長さぶんだけ音が上がり、長い経路には最後にもう一段上の音が乗ります。
なぞっている最中も、マスをつなぐたびに音が一段ずつ上がります。
上がるのは打ち消しを除いた長さの分だけなので、打ち消す手を踏むと音は一段下がります。
「音あり」のボタンで消せます。

残り10秒を切ると、秒読みの音が鳴り、画面の縁が赤く脈打ちます。
残りが少ないほど強くなります。
秒数は立体の後ろに大きく出ます。始まる前の3、2、1も同じ場所に同じ大きさで出ます。

## 盤面は URL の日付で決まる

`?date=2026-09-11` のように、URL に日付を付けるとその日の盤面になります。
日付が同じなら、誰がいつ開いても同じ配置です。
日付は日本時間で解釈します。世界のどこで開いても、切り替わるのは日本時間の午前0時です。

日付のない URL は、開いた瞬間に当日の盤面へ置き換わります。
過去の日付を手で打てば、その日の盤面で遊べます。

## 記録と再生

1回の試合は、盤面の日付と、なぞった順序だけで決まります。
終了画面の「リプレイ」を押すと、その2つを入れた URL へ移り、同じ盤面が同じ順序で再生されます。
そのアドレスを渡せば、相手も同じ試合を見られます。

再生中は「一時停止」で止められます。
同じ盤面を自分で遊ぶには「自分で挑戦」を押してください。

記録は時刻付きで圧縮して `&rec=` に入っています。
時刻はゲーム内の時計で数えているので、再生する端末の速さや、途中でタブを離れたかどうかには影響されません。

# 考え方と攻略

ここからはルールではなく、勝ち方の話です。
盤面の裏側にある群がわかると、当てずっぽうに引く回数がぐっと減ります。

## 背景にある群

`a`、`b`、`c` が生む回転は全部で12通りで、これは**4次交代群 A₄** と呼ばれる群になっています。
正四面体を正四面体に重ねる回転がちょうど12通りある、という事実がそのまま盤面になっているわけです。

覚えておく関係式は2つだけです。

- `a` を3回続けると元に戻ります（`a a a` = `e`）。`b`、`c` も同じです。
- `a`、`b`、`c` をこの順に1回ずつ通っても元に戻ります（`a b c` = `e`）。

「なぞった経路が消える」は、なぞった字を左から並べた語が `e` になる、と言い換えられます。
ですから攻略は、`e` になる語を盤面の上に探す作業になります。

## 3手で戻る形は2種類だけ

打ち消しを含まない3手で `e` になる並びは、全部で12通りあります。
そしてその12通りは、次の2種類に尽きます。

- **同じ字を3つ** — `a a a`、`b b b`、`c c c`、および `a⁻¹ a⁻¹ a⁻¹` などの逆元版。
- **3字を巡回順に1つずつ** — `a b c`、`b c a`、`c a b`。逆元だけなら逆回りの順で、`a⁻¹ c⁻¹ b⁻¹`、`b⁻¹ a⁻¹ c⁻¹`、`c⁻¹ b⁻¹ a⁻¹`。

大事なのは**順番が効く**ことです。
`a b c` は戻りますが、`a c b` は戻りません。
`a` → `b` → `c` → `a` の向きに回る順だけが当たりです。

もう一つ。
3手で戻る並びは、**3手すべてが同じ向き**です。
塗りつぶしと白抜きが混ざった3手は、どう並べても戻りません。
理由はあとの「なぞる前に分かること」でわかります。

## 4手で戻る形

4手だと60通りに増えますが、こちらにも見分け方があります。

4手で戻る並びは、必ず**時計回り2つと反時計回り2つ**です。
3つと1つ、4つと0つは戻りません。

覚えやすい形が一つあります。

- **`a b⁻¹` を2回** — `a b⁻¹ a b⁻¹` は戻ります。`a c⁻¹`、`b c⁻¹` など、字が違って向きが逆の組なら何でも同じです。

これは `a b⁻¹` が2回で元に戻る元（位数2の元）だからです。
盤面で塗りつぶしと白抜きが市松模様に並んでいたら、この形が眠っていないか見てください。

## なぞる前に分かること

時計回りの手数から反時計回りの手数を引いた値は、**3で割った余りだけなら経路の組み方によらず決まります**。
元の向きの余りは0です。

だから、差が3の倍数でない経路は、最後まで回してみるまでもなく戻りません。
長い経路を引く前に、塗りつぶしと白抜きの数を数えるだけで捨てられます。

3手と4手の話もこれで説明できます。
3手の差は3、1、−1、−3 のどれかで、3の倍数になるのは ±3、つまり全部が同じ向きのときだけです。
4手の差は4、2、0、−2、−4 で、3の倍数は0だけ。だから2つと2つになります。

逆は成り立ちません。
差が3の倍数でも戻らない経路はあります。
余りが0になる向きは12通りのうち4通りあり、そのうち元の向きは1つだけだからです。

ただしこれも使えます。
余りが0なのに戻っていないとき、四面体は残り3通りのどれかにいて、そのどれもが**あと2手で元に戻せる**向きです。
`a b⁻¹` のように字が違って向きが逆の2手を足せば届きます。

## 攻略

**長い経路は3手をつなぐ。**
コンボを伸ばしたいときは、`a a a` と `a b c` を数珠つなぎにすると考えてください。
6手は3手を2つ、9手は3つです。
`e` になる語をつないでも `e` なので、盤面の上で行き来できる限り伸ばせます。

これは好みの話ではなく、唯一の方法です。
6手以内に一度は戻す必要があるので、長い経路は必ず短い成立の連なりになります。
3手の形をひとつ覚えておくと、そこからどこへでも伸ばせます。

**打ち消しは橋になる。**
打ち消し合う2手は数に入りませんが、経路としてはつながります（盤面では中抜きの橋に見えます）。
成立する形が2箇所に離れているとき、間を打ち消しの組で渡ると、1回のなぞりでまとめて消せます。
消去に入るのは打ち消しを除いた分だけですが、成立は1回で済み、時間の節約になります。

6手の制限にも入らないので、橋は**いつでも、好きなだけ長く**渡れます。
なぞりの最初からでも構いません。
ただし**組を閉じきること**が条件で、片割れだけ踏んだ状態は1手進んだ扱いです。
盤面を読んで逆手の組を拾っていく手なので、これは彷徨いではありません。

払うのはマスと時間です。
橋の2マスは盤面から消えますが消去には入らず、なぞる時間も普通にかかります。

**入れ替えは、道を1マス伸ばすために使う。**
あと1マスで形になるのに、そこだけ向きが違う——という場面が一番の使いどころです。
隣に欲しい手があるなら、2マスなぞって持ってきてください。
何にも数えませんが、入れ替えたあとの盤面で成立が伸びます。

捨てる手ではないので、盤面は減りません。
どのマスも消えず、知らないマスも降ってこないので、入れ替えの結果は最初から全部見えています。
時間だけを払って、見えている盤面を組み替える手です。

**立体を見すぎない。**
回転は1手0.3秒です。
6手の経路を最後まで目で追えば2秒近くかかり、60秒の3%が1回のなぞりで消えます。
字を読んで形を決め、立体は確認に使う——そのほうが速く回ります。
