# 早見表

急ぐ人はここだけで遊べます。
理由はこの下の各節にあります。

## 簡単な遊び方

- `a a a` = `b b b` = `c c c` = `e`
- 逆元も同じで、`a⁻¹ a⁻¹ a⁻¹` = `e`
- `a b c` = `b c a` = `c a b` = `e`
- 逆元だけなら逆回りで、`c⁻¹ b⁻¹ a⁻¹` = `e`
- 2マスでリリースすれば入れ替わります。
- 一度も戻らないまま6手進むと、その経路は無効です。
- ワンストロークで成立（`e`）をつなげばコンボ。

## 中級編

- `a` = `a⁻¹ a⁻¹` です。これを使えば `a⁻¹ a⁻¹ b c` = `e`、`a b⁻¹ b⁻¹ c` = `e`
- 逆回りに適用すれば `c c b⁻¹ a⁻¹` = `e`
- `a a⁻¹` = `e` だけど、スコアにはカウントされません。離れたところにある「成立」をつなぐのには使えます。

## 上級編

- `a c a⁻¹` = `b`（共役）
- `a b c` = `e` の `b` を置き換えれば `a a c a⁻¹ c` = `e`
- 共役をマスターすれば、より多くの盤面でコンボを狙えます。

# マスの意味

盤面は5×5で、どのマスにも正四面体を回す操作が一つ入っています。

正四面体には角が4つあり、`e` と書かれた面を囲む3つに `a`、`b`、`c` の印が付いています。
`e` の面は、元の向きのときに手前を向いている面です。
マスの操作は、印の付いた三つの角のどれかを軸にして、正四面体を120°回すことです。
塗りつぶした点 (`a`, `b`, `c`) は時計回り、白抜きの点 (`a⁻¹`, `b⁻¹`, `c⁻¹`) は反時計回りを表します。

正四面体を回転させても a, b, c はそのままです。 aaa と順になぞれば e が元の位置に戻ります。ここで指を離せば消える、ということになります。

斜めにはつながりません。
一度通ったマスをもう一度通ることもできません。

# 打ち消し

打ち消しとは、隣り合う `a` と `a⁻¹` のように、同じ軸で向きが逆の2手のことです。
3マス以上の手の中に打ち消しが含まれている場合、その部分は得点になりません。道は繋がるので、遠くの成立へと繋ぐ橋として使用可能です。

`abb⁻¹a⁻¹` のように入れ子になっていても同様の扱いとなります。

# 6マスルール

**一度も元の向きに戻らないまま6マス進むと、その経路はもう成立しません。**
打ち消しはカウントされません。打ち消しを除いた6マスで判定されます。
一度引き返し、6マス以内に成立する道を探してください。成立したまま指を離さなければさらに道を伸ばすことができます。

## 6マスルールの意図
この制限がない場合、無作為にマスをつなぎ、最後の数マスでつじつまを合わせれば容易に最長記録を伸ばせます。成立の多様性を楽しんでもらうために制限を加えました。


# スコア

3つ数えます。

- **消去** — 消えたマスの数の合計。ただし打ち消し合うマスは除きます。
- **成立** — 元の向きに戻った回数。**1回のなぞりの中で何度戻ったかを、それぞれ数えます。**
- **コンボ** — 1回のなぞりが何回の成立でできていたか、その最大値。

例えば3マスの成立を4セット連ねて1回のストロークで消した場合、消去は +12、成立は +4 、コンボは 4 となります。

## コンボの上限は8

ひとつの成立には打ち消しを除いて最低3手が要り、盤面は25マスしかありません。
3 × 8 = 24 なので、8回が限界です。

# 立体の見かた

画面の四面体は、いまの向きをそのまま映しています。
面の一つに `e` が書いてあり、これが手前に正しく見えている状態が元の向きです[^e]。
経路が閉じた瞬間に `e` が光るので、指を離す前に成立を確かめられます。

四面体は、マスをつなぐたびにその場で回ります。
1手あたり0.3秒かけて回るので、全部の回転を目で追うと、そのぶん時計が減ります。
見て確かめるか、字を読んで先に決めるか——そこが持ち時間の使いどころです。

[^e]: `e` は群の単位元の記号で、「何もしない操作」を指します。

## 音と、残り10秒

消えたときは経路の長さぶんだけ音が上がり、長い経路には最後にもう一段上の音が乗ります。
なぞっている最中も、マスをつなぐたびに音が一段ずつ上がります。
上がるのは打ち消しを除いた長さの分だけなので、打ち消す手を踏むと音は一段下がります。
「音あり」のボタンで消せます。

残り10秒を切ると、秒読みの音が鳴り、画面の縁が赤く脈打ちます。
残りが少ないほど強くなります。
秒数は立体の後ろに大きく出ます。始まる前の3、2、1も同じ場所に同じ大きさで出ます。

## 盤面は URL の日付で決まる

`?date=2026-09-11` のように、URL に日付を付けるとその日の盤面になります。
日付が同じなら、誰がいつ開いても同じ配置です。
日付は日本時間で解釈します。世界のどこで開いても、切り替わるのは日本時間の午前0時です。

日付のない URL は、開いた瞬間に当日の盤面へ置き換わります。
過去の日付を手で打てば、その日の盤面で遊べます。

## 記録と再生

1回の試合は、盤面の日付と、なぞった順序だけで決まります。
終了画面の「リプレイ」を押すと、その2つを入れた URL へ移り、同じ盤面が同じ順序で再生されます。
そのアドレスを渡せば、相手も同じ試合を見られます。

再生中は「一時停止」で止められます。
同じ盤面を自分で遊ぶには「自分で挑戦」を押してください。

記録は時刻付きで圧縮して `&rec=` に入っています。
時刻はゲーム内の時計で数えているので、再生する端末の速さや、途中でタブを離れたかどうかには影響されません。

# 背景にある群

`a`、`b`、`c` が生む回転は全部で12通りで、これは**4次交代群 A₄** と呼ばれる群になっています。
正四面体を正四面体に重ねる回転がちょうど12通りある、という事実がそのまま盤面になっているわけです。

覚えておく関係式は2つだけです。

- `a` を3回続けると元に戻ります（`a a a` = `e`）。`b`、`c` も同じです。
- `a`、`b`、`c` をこの順に1回ずつ通っても元に戻ります（`a b c` = `e`）。

「なぞった経路が消える」は、なぞった字を左から並べた語が `e` になる、と言い換えられます。
ですから攻略は、`e` になる語を盤面の上に探す作業になります。

## 3手で戻る形は2種類だけ

打ち消しを含まない3手で `e` になる並びは、全部で12通りあります。
そしてその12通りは、次の2種類に尽きます。

- **同じ字を3つ** — `a a a`、`b b b`、`c c c`、および `a⁻¹ a⁻¹ a⁻¹` などの逆元版。
- **3字を巡回順に1つずつ** — `a b c`、`b c a`、`c a b`。逆元だけなら逆回りの順で、`a⁻¹ c⁻¹ b⁻¹`、`b⁻¹ a⁻¹ c⁻¹`、`c⁻¹ b⁻¹ a⁻¹`。

大事なのは**順番が効く**ことです。
`a b c` は戻りますが、`a c b` は戻りません。
`a` → `b` → `c` → `a` の向きに回る順だけが当たりです。

もう一つ。
3手で戻る並びは、**3手すべてが同じ向き**です。
塗りつぶしと白抜きが混ざった3手は、どう並べても戻りません。
理由はあとの「なぞる前に分かること」でわかります。

## 4手で戻る形

4手だと60通りに増えますが、こちらにも見分け方があります。

4手で戻る並びは、必ず**時計回り2つと反時計回り2つ**です。
3つと1つ、4つと0つは戻りません。

覚えやすい形が一つあります。

- **`a b⁻¹` を2回** — `a b⁻¹ a b⁻¹` は戻ります。`a c⁻¹`、`b c⁻¹` など、字が違って向きが逆の組なら何でも同じです。

これは `a b⁻¹` が2回で元に戻る元（位数2の元）だからです。
盤面で塗りつぶしと白抜きが市松模様に並んでいたら、この形が眠っていないか見てください。

## 印の無い4つめの角

正四面体の角は4つですが、印が付いているのは `e` の面を囲む3つだけです。
残る1つ——`e` の裏に隠れている角——にも、そこを軸にした120°回転はちゃんとあります。
**ただし、その手を持つマスはありません。**

12通りの向きの内訳はこうです。

- 元の向き … 1通り
- 角を軸にした120°回転 … 4つの角 × 2方向 = 8通り
- 辺のあいだを通る180°回転 … 3通り

このうちマスになっているのは、印の付いた3つの角の分、つまり6通りだけです。
4つめの角の2通りは、1マスでは書けません。

書くには2手要ります。

- `a c`、`b a`、`c b` — 片方の向き
- `a⁻¹ b⁻¹`、`b⁻¹ c⁻¹`、`c⁻¹ a⁻¹` — もう片方の向き

### 同じ2マスでも、なぞる向きで行き先が変わる

ここが4つめの角の一番の実害です。

- **巡回順**の2手は1手に化けます。`a b` = `c⁻¹`、`b c` = `a⁻¹`、`c a` = `b⁻¹`
- **逆順**の2手は4つめの角へ行きます。`a c`、`b a`、`c b`

`a` と `b` が隣り合っているとき、`a` → `b` と `b` → `a` は別のところへ連れていきます。
前者は `c⁻¹` を1マスで踏んだのと同じで、後者は盤面に書けない向きです。

（向きの混ざった2手——`a b⁻¹` など——はどちらでもなく、[4手で戻る形](#4手で戻る形)の180°回転になります。）

### 通り道としてだけ使う

4つめの角に居るとき、元の向きまでは**最短でも2手**かかります。
逆順の2手を踏んでしまったら、その2手を打ち消すか、そこから続けて形を作るかです。

なぞりの途中で通るぶんには何の問題もありません。
問題になるのは、そこで指を離したときだけです。

## 共役で字を入れ替える

`a c a⁻¹` は `b` と同じ回転です。
打ち消し合う2手で挟むと、真ん中の字が別の字に化けます。
これを**共役**といいます。

一手に化けるのは3つだけです。

- `a c a⁻¹` = `b`
- `b a b⁻¹` = `c`
- `c b c⁻¹` = `a`

どれも「**一つ前の字を挟むと、一つ次の字になる**」形です（`a` → `b` → `c` → `a` の巡回で）。

残りの3つ——`a b a⁻¹`、`b c b⁻¹`、`c a c⁻¹`——は**3つとも同じ回転**になり、しかもそれは盤面に無い手です。
`e` の裏に隠れている、印の付いていない4つめの角を軸にした回転だからです。
軸が3つしか印されていない以上、この回転を1マスで書くことはできません。

使い道は字の置き換えです。
`a b c` = `e` の `b` を `a c a⁻¹` に差し替えると:

```
a (a c a⁻¹) c  =  a a c a⁻¹ c  =  e
```

`b` のマスが近くに無くても、`a`、`c`、`a⁻¹` が並んでいれば成立が作れる、ということです。

ただし手数は増えます。
1文字が3文字になるので、3手の形は5手になります。
2文字置き換えると7手で、6手の制限を超えて無効です。
**1つの区間につき、共役は1回まで**と覚えてください。

## なぞる前に分かること

時計回りの手数から反時計回りの手数を引いた値は、**3で割った余りだけなら経路の組み方によらず決まります**。
元の向きの余りは0です。

だから、差が3の倍数でない経路は、最後まで回してみるまでもなく戻りません。
長い経路を引く前に、塗りつぶしと白抜きの数を数えるだけで捨てられます。

3手と4手の話もこれで説明できます。
3手の差は3、1、−1、−3 のどれかで、3の倍数になるのは ±3、つまり全部が同じ向きのときだけです。
4手の差は4、2、0、−2、−4 で、3の倍数は0だけ。だから2つと2つになります。

逆は成り立ちません。
差が3の倍数でも戻らない経路はあります。
余りが0になる向きは12通りのうち4通りあり、そのうち元の向きは1つだけだからです。

ただしこれも使えます。
余りが0なのに戻っていないとき、四面体は残り3通りのどれかにいて、そのどれもが**あと2手で元に戻せる**向きです。
`a b⁻¹` のように字が違って向きが逆の2手を足せば届きます。

## 攻略

**長い経路は3手をつなぐ。**
コンボを伸ばしたいときは、`a a a` と `a b c` を数珠つなぎにすると考えてください。
6手は3手を2つ、9手は3つです。
`e` になる語をつないでも `e` なので、盤面の上で行き来できる限り伸ばせます。

これは好みの話ではなく、唯一の方法です。
6手以内に一度は戻す必要があるので、長い経路は必ず短い成立の連なりになります。
3手の形をひとつ覚えておくと、そこからどこへでも伸ばせます。

**打ち消しは橋になる。**
打ち消し合う2手は数に入りませんが、経路としてはつながります（盤面では中抜きの橋に見えます）。
成立する形が2箇所に離れているとき、間を打ち消しの組で渡ると、1回のなぞりでまとめて消せます。
消去に入るのは打ち消しを除いた分だけですが、成立は1回で済み、時間の節約になります。

6手の制限にも入らないので、橋は**いつでも、好きなだけ長く**渡れます。
なぞりの最初からでも構いません。
ただし渡るのは6手を使い切る前です。
使い切ってしまえば橋も架けられません。
ただし**組を閉じきること**が条件で、片割れだけ踏んだ状態は1手進んだ扱いです。
盤面を読んで逆手の組を拾っていく手なので、これは彷徨いではありません。

払うのはマスと時間です。
橋の2マスは盤面から消えますが消去には入らず、なぞる時間も普通にかかります。

**入れ替えは、道を1マス伸ばすために使う。**
あと1マスで形になるのに、そこだけ向きが違う——という場面が一番の使いどころです。
隣に欲しい手があるなら、2マスなぞって持ってきてください。
何にも数えませんが、入れ替えたあとの盤面で成立が伸びます。

捨てる手ではないので、盤面は減りません。
どのマスも消えず、知らないマスも降ってこないので、入れ替えの結果は最初から全部見えています。
時間だけを払って、見えている盤面を組み替える手です。

**立体を見すぎない。**
回転は1手0.3秒です。
6手の経路を最後まで目で追えば2秒近くかかり、60秒の3%が1回のなぞりで消えます。
字を読んで形を決め、立体は確認に使う——そのほうが速く回ります。
