# 出典

Scientific American 2008年7月号の記事「Simple Groups at Play」で紹介された3つのパズルを再現したものです。
記事は日経サイエンス 2008年10月号に翻訳掲載されました。

- [日経サイエンス「3つのパズル」](https://www.nikkei-science.com/threePuzzle.ntml)

3つとも、散在型単純群（またはその近く）の元を、並べ替えや表の変化として見せるパズルです。

# M₁₂ パズル

1〜12 の数の並びを、昇順に戻します。
使える操作は2つだけです。

| 操作   | キー | 何をするか                                              |
| ------ | ---- | ------------------------------------------------------- |
| 逆順   | I    | 並びを逆にする                                          |
| 綾織り | M    | 先頭と末尾から交互に取って並べ直す（1, 12, 2, 11…の順） |

とりうる並びは 95,040 通りで、マシュー群 M₁₂ の位数と同じです。
「ヒント」を押すと、全状態の最短手数から次の一手を示します。

# M₂₄ パズル

円周に並んだ 1〜23 と、外側の 0 を元の位置に戻します。
円の内側の小さな数字が、その位置に入るべき数です。

| 操作     | キー | 何をするか                                     |
| -------- | ---- | ---------------------------------------------- |
| 左回り   | ←    | 円を1目盛り反時計回りに回す。外の 0 は動かない |
| 右回り   | →    | 円を1目盛り時計回りに回す。外の 0 は動かない   |
| 入れ替え | S    | 同じ色の円にある数どうしを交換する             |

とりうる並びは 244,823,040 通りで、マシュー群 M₂₄ の位数です。

# Dotto

24 × 24 の数の表を、最初の表に戻します。
使える操作は4つです。

| 操作       | キー | 何をするか                                                                                        |
| ---------- | ---- | ------------------------------------------------------------------------------------------------- |
| 右回り     | R    | 円を1目盛り回す。0 の列は動かず、1→2→…→23→1 と列が移る                                            |
| 入れ替え   | M    | 各テトラッドで、黄色の列どうし・青の列どうしを入れ替える                                          |
| 符号反転   | S    | 最初の8列（最初の2テトラッド）の符号を変える                                                      |
| テトラッド | T    | 各行・各テトラッドで、4つの数の和の半分を各数から引く。そのあと最初のテトラッドの列の符号を変える |

縦線で区切られた4列ずつが、テトラッドです。
表の下の番号を2つ続けて押すと、1つ目の番号の列が2つ目の番号の位置へ、円の回転で移ります。

これらの操作で作られる群は、コンウェイ群 Co₀（位数 8,315,553,613,086,720,000）です。

## 攻略のヒント

- どの操作をしても、各行の数の2乗和は変わりません（1行目は 64、ほかの行は 32）。
- 1行目に 8（または −8）を出せれば、あとは M₂₄ の操作（R, M）と符号反転（S）だけの問題になります。
- 元の表に戻ったとき、対角線上の数はすべて正になっています。
- 符号だけが違い、間違っているのが8列だけなら、その8列は R と M だけで最初の8列に移せます。そのあと S で直せます。

# 操作

どのパズルも、ボタンを押すかキーで操作します。
U でひとつ戻せます。
「最初の配置に戻す」はシャッフル直後の配置に、「新しくシャッフル」は別の配置にします。

# 再現について

原作の図をすべては確認できていないため、次の部分は記事の条件を満たすように再構成しています。

- **M₁₂ の綾織り**：説明文の「先頭側と末尾側を合わせる」という記述から、先頭と末尾から交互に取って並べ直す操作にしました。「逆順」と組み合わせて生成される群の位数が、M₁₂ と同じ 95,040 になることを計算で確かめています。
- **M₂₄ の配色**：「回転」と「同色の円どうしの入れ替え」で M₂₄ 全体（位数 244,823,040）が生成されるように再構成した配色です。原作とは配色が違う可能性があります。
- **Dotto**：説明文にある4つの操作（R, M, S, T）を、表の列に対する操作としてそのまま実装しました。列の並び、黄と青の色分け、最初の表は、条件を満たすように再構成したものです。R, M, S, T で作られる群が Co₀ と一致することの確認として、Leech 格子の最短ベクトル 196,560 個がすべて1つの軌道になることを計算で確かめています。
